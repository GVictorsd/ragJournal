# Career Planning

I started the year by writing down what I want from my career over the next two years. I want to become a stronger software engineer rather than simply collecting more framework names. My main technical goals are system design, cloud infrastructure, backend engineering, and practical AI application development. I also want to become more comfortable explaining trade-offs in interviews. A recurring problem in my learning is that I read about many subjects without building enough things. I am changing that by attaching each major topic to a project. For example, I want to learn retrieval-augmented generation by building a private journal assistant. The project should let me ask questions about old entries, retrieve relevant passages, and show the evidence used for an answer. I wrote down this plan because I want to be able to look back later and see whether my actual work matched my intentions.
