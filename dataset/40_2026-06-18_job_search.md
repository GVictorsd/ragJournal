# Job Search

I reviewed several job descriptions and created a spreadsheet of recurring requirements. JavaScript and TypeScript appeared frequently, along with React, REST APIs, cloud services, databases, and testing. AI-oriented roles added Python, LLM APIs, RAG, agents, vector databases, and prompt engineering. Instead of treating every requirement as equally urgent, I grouped them into strengths, working knowledge, and learning priorities. This made the job search feel more concrete. I also started collecting examples from my projects that demonstrate each skill. I want applications to be evidence-based, with specific projects and outcomes rather than long lists of technologies.
