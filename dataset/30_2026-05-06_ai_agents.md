# AI Agents

I studied the difference between a normal LLM call and an agentic workflow. A normal call can answer a question from the prompt, while an agent can decide to use tools, retrieve information, perform steps, and potentially delegate subtasks. I experimented with a small workflow where one component retrieves documents and another generates a response based on the retrieved evidence. The orchestration layer is important because it controls what tools can be used and how results are passed between steps. I am interested in agent systems, but I want to avoid using an agent simply because the word sounds advanced. If a deterministic pipeline solves the problem, it may be easier to test and operate.
