# Future Ideas

I wrote down several possible extensions for the journal assistant. One idea is temporal reasoning, where the system could summarize how a goal or opinion changed over time. Another is topic clustering to reveal themes that were not explicitly tagged. I would also like to add image retrieval for travel photographs and perhaps a graph connecting people, places, projects, and events. An agentic mode could decide whether to use keyword search, vector search, metadata filters, or a timeline tool depending on the question. However, I want to finish and evaluate the core RAG pipeline first. Adding agents before the retrieval foundation is reliable would make the system more complicated without necessarily making it better.
