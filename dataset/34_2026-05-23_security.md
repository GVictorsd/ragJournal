# Security

I reviewed basic web application security concepts with a focus on authentication, authorization, secrets, and input validation. One point that stood out was that authentication and authorization solve different problems. Knowing who a user is does not automatically determine what they are allowed to do. I also looked at how API keys should be stored and why secrets should never be committed to source control. For the journal application, privacy is particularly important because the documents may contain personal information. I want to design the system so that local development is possible without sending the entire journal corpus to third-party services unnecessarily.
