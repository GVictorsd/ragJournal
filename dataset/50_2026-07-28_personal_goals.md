# Personal Goals

I reviewed the goals I wrote in January. Some have progressed well, especially AI experimentation and system design. Others, such as reading a fixed number of books, were less useful because the number itself did not represent learning. I am changing the goal format from activity counts to outcomes. Instead of “read four books,” I might write “understand and apply two architectural ideas.” Instead of “complete a cloud course,” I can aim to deploy and operate one application. This feels more aligned with the kind of engineer I want to become.
