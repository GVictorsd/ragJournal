# Agent Evaluation

I designed a small evaluation set for the journal assistant. The questions are divided into factual lookup, multi-entry synthesis, temporal questions, negative questions, and ambiguous questions. Factual lookup might ask when I studied caching. Multi-entry synthesis might ask how my views on learning changed over several months. Negative questions test whether the system admits that a fact is absent. Ambiguous questions test whether it asks for clarification or retrieves a reasonable set of possibilities. I also want to measure retrieval recall separately from answer quality. A good language model cannot compensate for retrieving the wrong evidence.
