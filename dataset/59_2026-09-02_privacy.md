# Privacy

I reviewed the privacy implications of storing a personal journal in an AI application. The corpus could contain sensitive thoughts, names, locations, and financial details, so I do not want to treat it like a generic public dataset. I am considering local embeddings and a local vector database for development. If an external model is used for generation, I want the application to send only the retrieved context needed for the question. I also want a way to delete an entry and its associated vector reliably. Privacy should be part of the architecture rather than a feature added after the demo is finished.
