# Family Memory

I spent some time looking at old family photographs and asking relatives about events I only partially remembered. Some memories were surprisingly different from what I thought had happened. This reminded me that personal memory is incomplete and sometimes inaccurate. If a journal assistant is going to answer questions about the past, it should distinguish between written evidence and generated interpretation. I want source citations to be a core part of the interface. If an answer says that I enjoyed a particular trip, I should be able to open the entries that support that conclusion.
