# Cloud Learning

I started a structured study plan for cloud infrastructure. Instead of learning three cloud platforms simultaneously, I decided to first understand concepts such as compute, networking, storage, identity, containers, queues, monitoring, and managed databases. Provider-specific services can come afterward. I deployed a small application locally with a frontend, API, database, and worker and started documenting what would be needed to run the same system in the cloud. This exposed gaps in my understanding of secrets, networking, health checks, and observability. I am finding that infrastructure becomes easier to understand when I have a concrete application to map concepts onto.
