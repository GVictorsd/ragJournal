# AI Learning

I spent the evening studying the basic architecture of retrieval-augmented generation. The pipeline seems simple at a high level: documents are processed, chunks are created, embeddings are generated, relevant chunks are retrieved, and a language model uses those chunks to produce an answer. The difficult part is making retrieval reliable. A model can generate a fluent answer even when the retrieved context is poor, so the application needs a way to inspect what was retrieved. I want my journal assistant to show source entries alongside generated responses. That will make the demo more educational because I can demonstrate both successful retrieval and failure cases.
